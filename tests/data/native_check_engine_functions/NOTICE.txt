Scope

These tests execute selected original functions with synthetic CPU inputs.
They do not start either full engine, a server, a GPU job, or transport work.
The canary case executes SGLang's original Torch CPU reference function and
host health function. It does not execute the CUDA kernel. The dispatch source
explicitly selects the Torch reference for CPU devices.

The SGLang expected-zero case proves admission without comparison. It does not
prove a live decode-only deployment or an explicit native passing verdict.
The canary case proves counter activity with an empty plan, not a request pass.
The vLLM case proves a true native aggregate return while a declared transferred
group is not compared. It is a synthetic comparison, not measured serving data.

The fixture manifest marks these cases synthetic and not release qualifying.
Pure classification controls are not runtime integration or release evidence.
