Add your GPU: pip install sdcguard && sdcguard check --share, then press Submit on the issue it opens. Results are self-reported and come from GitHub issues; each card carries a digest of its contents, hardware IDs are hashed, and every FAIL or SUSPECT links to its issue. Simulated-fault demos, CPU runs and runs under a minute are left out. Raw data: results.json, reference.json. Code and docs on GitHub.
